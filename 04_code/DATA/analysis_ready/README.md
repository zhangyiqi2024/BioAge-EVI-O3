# Restricted analysis input 🔐

The public release does not include analysis_dataset.dta. The local author workspace
may contain this restricted CHARLS-derived dataset; it is deliberately excluded by
the release builder and ignore rules. Obtain CHARLS access directly from
https://charls.pku.edu.cn/ and follow DATA/BUILD_SCOPE.md.

codebook.csv lists all 205 English variable names, labels and value codes without
participant examples. BAA_PhenoAge and the spatial exposure summaries are supplied
upstream inputs; the package does not claim complete raw-data reconstruction.
